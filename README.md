# Celestine Chord

Full-colour Python 3 neon four-lane **rhythm-tap** arcade for [ElbowOS](https://x.com/ElbowOS).

Notes fall the ice-indigo lanes. Tap **D F J K** on the hit bar.
White-rimmed gems are **chords** — hit every lane in the pack together for a bonus.

## Play

```bash
pip install -r requirements.txt
python3 celestine_chord.py --play
```

Keys: `D F J K` tap lanes, `R` reset, `Esc` quit.

## Record a 9:16 reel

```bash
python3 celestine_chord.py --record
```

Writes a 1080x1920 h264 clip (15s @ 30fps) with title, score, and `x.com/ElbowOS` burned into the frames.
